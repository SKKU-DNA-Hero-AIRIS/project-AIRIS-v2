# 6주 계획과 역할

## 목표

체형과 시나리오(일반, 임산부, 휠체어)에 따라 에어게이트 통과 시 먼지가 가장 잘 제거되는 **정적 자세**를 찾는다. 노즐은 고정 배치이며, 동적 조절은 README 12절의 확장 항목이다.

- 시뮬레이터: Taichi GPU 입자 기반 (해석적 제트장 + 충돌 보정 + 부착력 분포로 옷감 근사)
- 최적화: CMA-ES (시나리오 × 체형별)
- 일반화: 최적화 결과를 라벨로 회귀 모델 학습 → 실시간 포즈 추정과 연결
- 검증: 패치 기준선과 비교, 물리 상수 민감도, 상위 후보를 LBM 유체 솔버로 재평가

트랙별 상세 구현 계획은 `docs/tracks/` (공통 규약 `00_common.md`, 트랙 A/B/C/D). 병렬 세션 개발 시 각 세션은 공통 규약과 자기 트랙 문서만 읽고 시작한다.

## 체크포인트

- **1주차 말**: 패치판으로 `scripts/run_optimize.py`가 끝까지 돈다. 정성 테스트 5개가 활성화되어 통과한다.
- **2주차 말**: 입자판 `batch_evaluate`가 같은 스크립트에 꽂혀서 돈다. 계산 기간 시작.
- **3주차 말**: 민감도 결과로 "순위가 상수에 안정적인가" 판정. 불안정한 상수 목록 확정.
- **4주차 말**: 데이터셋 1차 완료, 회귀 1차 결과.
- **5주차 말**: LBM 검증 결과, 실시간 데모 동작.

## A가 밀릴 때

3주차까지 입자판 배치 실행이 안 되면 C는 패치판으로 데이터셋 생성을 시작하고, 입자판은 완성 후 상위 후보 재평가에만 쓴다.

## 협업 규칙

- `main` 보호 (직접 push 불가). 기능 브랜치 → PR → D 리뷰 → 병합. 병합 전 로컬에서 `pytest -q` 통과 확인.
- `configs/physics.yaml`은 B 소유. 다른 사람은 PR로만 수정.
- 실험은 전부 로그: 실험 ID, 커밋 해시, 설정 해시, 결과 경로. C가 `docs/experiments.md`에 표로 관리.
- 주 2회 통합 점검 (A+B는 추가로 주 2회 페어).
- 커밋 메시지: `feat|fix|test|docs|exp: 요약`. `exp:`는 실험 결과 커밋.

## 계산 예산

RTX 4090급 3주 상시 (약 500 GPU시간, 25~40만 원). 민감도 20~40h, 시나리오별 최적화 5~10h, 데이터셋 30~80h, LBM 검증 30~60h. 남는 예산은 입자 수 확대와 LBM 케이스 확대에 쓴다.
