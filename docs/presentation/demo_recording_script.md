# 시연 영상 녹화 대본 (40~60초)

실제 화면을 직접 녹화할 때 쓰는 대본입니다. 클릭 순서와 기다릴 시간이 적혀 있으니 그대로 따라 하면
한 번에 찍힙니다. 멘트는 영상에 음성을 넣을 때 쓰고, 자막으로 깔아도 됩니다.

## 준비 (녹화 시작 전)

1. 터미널에서 대시보드를 띄웁니다.
   ```
   cd C:\Users\SEONGWOO\Documents\airis-v2-realtime
   python -m streamlit run scripts/run_dashboard.py
   ```
2. 브라우저가 열리면 주소 끝에 **`?demo=1`** 을 붙여 다시 들어갑니다 (예시 이미지로 바로 시작합니다).
   → `http://localhost:8501/?demo=1`
3. **첫 화면이 다 그려질 때까지 기다립니다** (3D 그림 두 장이 나타날 때까지, 10~20초). 녹화는 그 다음에 시작합니다.
   첫 실행은 모델을 올리느라 느립니다. 두 번째부터 빠릅니다.
4. 브라우저 창을 최대화하고, 배율을 100% 로 둡니다 (Ctrl+0). 사이드바가 접혀 있으면 왼쪽 위 `»` 로 폅니다.
5. 녹화 시작: **Win + Alt + R** (Windows 게임 바). 멈출 때도 같은 키입니다.

> 녹화 중에는 마우스를 천천히 움직이세요. 클릭 후에는 화면이 다시 그려질 때까지 기다렸다가 다음 동작을 합니다.

## 알아 둘 것

- **2026-10-05 기준으로 다시 확인한 값입니다** (부스 안 판정 여유 2% 적용 뒤). 장면 4 는 벌림 173°·회전 77°,
  개선율 +134% / +57% / +109%. 장면 5 는 키 1.95 · 팔 0.60 에서 벌림 20°(팔 내림)로 바뀝니다.
  화면에 뜨는 각도는 5° 단위로 반올림되므로 "약 75도"로 말하면 됩니다.

- **장면 5의 숫자는 실제로 확인한 값입니다** (설치된 k 1.4 모델 기준). 예시 이미지 추정 체형(키 1.75, 팔 0.48)에서:
  - 키만 1.90 으로 → 팔을 **덜 드는** 자세로 바뀝니다 (팔 벌림 173° → 152°). 천장에 닿지 않게 낮춘 것이라
    변화가 미묘합니다. 짧게 보여 줄 때만 쓰세요.
  - **키 1.95 + 팔 길이 0.60** 으로 → 팔 벌림 약 **20°**, 즉 팔을 내린 자세로 확실히 바뀝니다. 대본은 이 값을 씁니다.
  - 키만 바꿔서는 팔 내림까지 가지 않습니다. "천장에 닿아 팔을 내렸다"고 말하려면 팔 길이도 함께 키워야 합니다.
- **응답 시간 표시**: ④ 아래에 "응답 시간 N초"가 나옵니다. 다른 계산이 CPU 를 쓰고 있으면 이 값이 커지고
  ⚠️ 가 붙습니다. 녹화 전에 무거운 실험이 돌고 있지 않은지 확인하세요 (한산할 때 1초 안팎입니다).
- **점수 이야기를 할 때**: 절대 제거율이 아니라 **기준 자세 대비 상대 비교값**입니다. "먼지가 몇 % 제거된다"가
  아니라 "안내 없이 통과할 때보다 몇 배"로 말해야 맞습니다.
- 장면 4·6 에서 3D 그림을 마우스로 돌리면 보기 좋습니다 (드래그). 다만 돌리는 동안은 멘트를 쉬세요.
- 한 번에 안 되면 장면별로 따로 찍어 이어 붙여도 됩니다. 장면 사이 전환은 편집에서 넣으면 됩니다.
