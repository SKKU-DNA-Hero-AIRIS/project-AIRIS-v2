규약: `docs/plan.md` 협업 규칙, `docs/tracks/C_optimize.md` 단계 4.

- **물리 기준**은 점수에 영향을 주는 설정 묶음이다. 기준이 바뀌면 이전 기록은 비교 대상이 아니므로 "무효" 절로 옮긴다.

요약
- 두 시작점을 쓰면 default 세 시드가 모두 "만세 + 옆으로 약 90° 회전"으로 모인다. 평균 0.6242 ± 0.0011이고, yaw ±90은 좌우 대칭이다.
- 시작점이 기본 자세 하나면 "팔 내림 + 옆으로 90° 회전"(0.5668 ± 0.0034)에 갇힌다. 후보 3,000개 중 벌림 ≥130°는 default 0개, wheelchair 1개였다.
- yaw 90에서 벌림 방향 단면은 15°에서 0.56, 135°에서 0.46(골), 180°에서 0.61이다. 불가 띠가 아니라 두 봉우리 지형이라 등급화 벌점만으로는 넘어가지 못한다.
- 격자 평가(벌림 130~180 × 팔꿈치 × 굽힘 × yaw)의 최고값은 default 0.6127, wheelchair 0.3721이었다. 두 시작점 CMA-ES가 둘 다 넘었다.
- pregnant도 만세 + 옆으로 약 90° 회전이다. 벌림 불편도 가중이 0.6으로 default의 두 배라, 팔 내림 봉우리와의 차이가 작다(0.5965 vs 0.5687).
- 좌우 대칭: 노즐 12개와 부스가 y 거울 대칭이라 yaw +θ와 −θ가 같은 점수다. 표의 yaw 부호는 임의다(`docs/interfaces.md` 회귀 모델 절의 거울 정규화 참고).
- 시간: default와 pregnant는 74~83 s로 1.5분 기준 안이다. wheelchair는 110~114 s로 기준을 넘는다(기록만).
