# 실험 기록

사람이 읽는 실험 요약이다. 소유자: C. 기계용 원장은 `outputs/index.csv`, 실행마다 `outputs/<exp_id>/`에 `meta.json`, `history.csv`, `best.json`이 남는다(`outputs/`는 git 밖).
규약: `docs/plan.md` 협업 규칙, `docs/tracks/C_optimize.md` 단계 4.

- **물리 기준**은 점수에 영향을 주는 설정 묶음이다(상수, 노즐, 부스, 보정, 몸 패치 격자). 기준이 바뀌면 이전 기록은 비교 대상이 아니므로 "무효" 절로 옮긴다.
- **개선율** = (best − 기준선) / |기준선|. 기준선은 같은 물리 기준에서 잰 B0(기본 자세), B1(몸 회전 12방향 평균), B2(만세)다(`airis/optimize/baselines.py`).
- 체형은 모두 `BodyParams()` 기본값이다(캡슐판 1.70 / 0.42 / 0.22 / 0.62 / 0.85, 메시판 1.70 / 0.342 / 0.194 / 0.463 / 0.883).
- 노즐·부스가 좌우 거울 대칭이라 yaw +θ와 −θ는 같은 자세로 본다. 표의 yaw 부호는 임의다(`docs/interfaces.md` 회귀 모델 절).

요약 (캡슐판과 비교)
- **세 시나리오 모두 15/15 "만세 + 옆으로".** 메시에서는 만세 우위가 커졌다. 봉우리 차가 default +0.085, pregnant +0.060, wheelchair +0.035로, 캡슐판(+0.023 / −0.007 / +0.017)보다 크다. E5에서 본 "메시 옆구리 R 감소로 만세 우위가 줄 수 있다"는 예상과 반대 결과다. 메시 다리 R 상승 등 다른 부위 효과가 더 크다.
- **pregnant가 팔 내림(캡슐판) → 만세(메시판)로 바뀌었다.**
- **wheelchair 회전이 45°(시나리오 상한, 캡슐판) → 약 36°로 바뀌었다.** 상체 pitch도 캡슐판 +4.4° → 메시 약 −0.5°다. E5의 "메시에서 숙이면 허벅지가 가려진다"와 맞는다.
- **앞뒤 등가**: default·pregnant의 |yaw|가 약 72°와 약 105°의 두 무리로 갈리는데 점수가 같다. 같은 자세를 yaw θ와 180° − θ로 평가하면 default s0에서 0.6533 / 0.6534로 사실상 같다. 노즐 배치가 x 방향으로 정확히 거울 대칭은 아니지만 점수는 거의 대칭이다. yaw를 90° 기준으로 한 번 더 접으면(90° − |90° − |yaw||) default 72.8 ± 2.1°, pregnant 78.5 ± 3.1°로 모인다. 회귀 데이터셋의 yaw 정규화에 반영할지 통합 관리에 제안한다.
- 시드 간 best 표준편차 0.0006~0.0031로 수렴이 안정적이다. 3,000회 시간은 110~172 s다.
