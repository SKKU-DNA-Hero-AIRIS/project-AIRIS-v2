# 실험 기록

사람이 읽는 실험 요약이다. 소유자: C. 기계용 원장은 `outputs/index.csv`, 실행마다 `outputs/<exp_id>/`에 `meta.json`, `history.csv`, `best.json`이 남는다(`outputs/`는 git 밖).
규약: `docs/plan.md` 협업 규칙, `docs/tracks/C_optimize.md` 단계 4.

- **물리 기준**은 점수에 영향을 주는 설정 묶음이다(상수, 노즐, 부스, 보정, 몸 패치 격자). 기준이 바뀌면 이전 기록은 비교 대상이 아니므로 "무효" 절로 옮긴다.
- **개선율** = (best − 기준선) / |기준선|. 기준선은 같은 물리 기준에서 잰 B0(기본 자세), B1(몸 회전 12방향 평균), B2(만세)다(`airis/optimize/baselines.py`).
- 체형은 모두 `BodyParams()` 기본값이다(캡슐판 1.70 / 0.42 / 0.22 / 0.62 / 0.85, 메시판 1.70 / 0.342 / 0.194 / 0.463 / 0.883).
- 노즐·부스가 좌우 거울 대칭이라 yaw +θ와 −θ는 같은 자세로 본다. 표의 yaw 부호는 임의다. 메시판부터는 앞뒤 등가(θ ≡ 180° − θ)도 적용해 요약에서 yaw를 0~90°(yaw*)로 접는다(`docs/interfaces.md` 회귀 모델 절, `e4.fold_yaw`). 좌우 거울은 메시에서도 정확하지만 **앞뒤 등가는 근사**다(상대차 약 2e−4, 아래 "yaw 접기 규약" 절).

### yaw 접기 규약은 앞뒤 등가가 근사다

`e4.fold_yaw` 는 좌우 거울(θ ≡ −θ)과 앞뒤 등가(θ ≡ 180° − θ)를 함께 접는다. `docs/e4_reference.json` 의 봉우리 21개를 raw 자세와 접은 자세로 각각 2,000/m² 에서 평가해 확인했다(`score` vs `score_folded`, E 교차 검증에서 나온 관찰, 2026-10-01).

- **좌우 거울은 사실상 정확하다**: 접기가 부호만 바꾼 13개에서 최대 차 **6.8e−10** (예: default 팔 내림 s1 의 −76.58° 0.4936651588 vs +76.58° 0.4936651595).
- **앞뒤 등가는 근사다**: 180° − θ 로 접힌 8개에서 차가 **1.3e−4(중앙값) ~ 2.6e−4(최대)** 다. 가장 큰 예는 pregnant 만세 s0 의 −103.77° 0.5889909 vs 76.23° 0.5887352. 메시 몸이 앞뒤로 완전 대칭이 아니라서다(상대차 약 4e−4).
- 요약·회귀 모델에는 그대로 쓰되 **점수를 인용할 때 어느 쪽 자세인지 밝힌다.** 기준 파일은 `score`(raw)와 `score_folded`(접은 자세)를 따로 싣는다.
- 요약·회귀 모델에는 그대로 쓰되, **점수를 인용할 때는 어느 쪽 자세의 점수인지 밝힌다.** `docs/e4_reference.json` 은 `pose_raw` 의 점수를 `score`, 접은 자세의 점수를 `score_folded` 로 따로 싣는다.

#### 읽을 점

- **계획은 자세 하나보다 확실히 낫다.** 어느 가중에서도 P5 > P2 이고, P0 대비 +279~771% 다. default w=0 에서 P2 0.6295 → P5 0.9531 이고 제거율도 0.1820 → 0.2891 이다.
- **단계 2개로는 12단계 회전(P1)을 못 이긴다.** 이 실행에서는 default 만 P5 > P1 이고 pregnant·wheelchair 는 P1 이 높았다(−0.02 ~ −0.05). **단계 수가 병목이었고, 아래 n_phases 스윕에서 N ≥ 3 이면 P5 가 P1 을 앞선다**(정정 2026-10-04).
- **에너지는 세기가 아니라 시간으로 아낀다.** P5 의 구역 세기는 어느 해에서도 0.80 이상이고(top 구역만 0.55~0.99로 조금 내려간다), 가중이 커지면 총 시간이 줄어든다: default 19.2 → 19.7 → 18.6 → 14.2 s, pregnant 15.5 → 13.1 → 14.5 → 9.4 s, wheelchair 15.1 → 17.0 → 19.1 → 11.7 s. P3·P4 는 더 뚜렷하다(P4 default 11.3 → 7.4 s).
- **한쪽 벽을 끄는 해는 나오지 않았다.** 12개 P5 해 모두 최소 구역 세기가 0.55 이상이다. pregnant 의 가슴 구역 0.60 은 최적화 결과가 아니라 시나리오의 쾌적 상한(`nozzle_strength_cap`)이다. D·A 가 본 "벽 구역을 끄면 torso_back 이 오른다"는 현상은 전체 점수에서는 이득이 아니었다.
- **2단계 자세는 둘 다 만세 + 옆으로다.** 벌림 155~180°, 접은 yaw 0~70°(default 45~56°, wheelchair 35~45°). 두 단계가 서로 다른 yaw 를 쓰는 해가 많다(예: default w=0 은 55° 와 57°, pregnant w=0.1 은 0° 와 70°).
- **P3(기본 자세 + 세기·시간만)은 거의 개선이 없다**(w=0 에서 +0%, w=0.1 에서 +62~98%는 P0 이 에너지 벌점으로 낮아진 탓이다). 자세·방향을 바꾸지 않으면 운전 조정만으로는 얻을 게 없다.

- 입자판으로 검증할 때는 **절대값이 아니라 순위·방향으로** 본다. A 측정에 따르면 입자판은 제거를 부스 이탈 시점에 집계해 짧은 계획에서 닫힌 식보다 낮게 나온다(2 s 에서 R/R∞ 0.496 vs 0.632). 위 해들의 단계 시간은 4.2~11.3 s 다.

- **N ≥ 3 이면 P5 가 P1 을 앞선다.** 본 실행에서 "P1 이 이긴다"로 보였던 것은 **단계 2개의 한계**였다. 단계를 늘리면 default 0.9218 → 1.0493, pregnant 0.5452 → 0.6488, wheelchair 0.5908 → 0.6643 으로 오른다(단조는 아니다 — pregnant N=4 가 N=3 보다 낮고, 시드 1개라 그 정도 흔들림은 잡음과 구분되지 않는다).

- **메시 몸은 팔을 들 때 옆구리·겨드랑이 제거율이 캡슐보다 훨씬 작다**(팔 150°에서 캡슐 0.078, 메시 0.0049; D 모델 한계 7번). 메시 옆구리 면이 아래를 향해 접선 속도가 줄기 때문이다. 캡슐판 만세 봉우리의 우위 일부가 이 옆구리 제거에서 왔다면 **메시판에서는 만세 우위가 줄거나 팔 내림으로 뒤집힐 수 있다**(C의 예상, 메시판 E4로 확인).
- C 재실행 순서: 5단계(`body.model: mesh`, 전역 BodyParams 기본값) 병합 후 E4 → E3 → 데이터셋. 캡슐판 절은 그대로 두고 메시판을 새 절로 적는다.
