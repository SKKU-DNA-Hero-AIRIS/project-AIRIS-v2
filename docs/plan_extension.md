# 세기·시간 확장 계획 (2026-09-29 총괄 확정)

> 기준 main `714b63c`. 공용 수식은 `docs/tracks/00_common.md` 4.4·4.6·4.7, 계약은 `docs/interfaces.md`, 타입은 `airis/sim/types.py`(`Phase`, `Plan`). 아래 결정 1~10은 추천안 그대로 확정.

자세 7개만 최적화하던 문제를 **자세 순서 + 구역별 세기 + 분사 시간**까지 넓힌다. 노즐 방향·높이는 구동 장치가 필요하므로 제외한다. 세기와 시간은 기존 장비에서 소프트웨어(팬 속도, 켜는 시간)로 바꿀 수 있는 값이다.

## 1. 지금 시뮬레이터로 안 되는 이유

| 항목 | 현재 | 문제 |
|---|---|---|
| 세기 | `NozzleConfig.strengths (M,)` 가 출구 속도 배수로 들어감 | 점수가 세기에 단조 증가(E1). 비용이 없어 최적화하면 전부 최대 |
| 시간 | 패치판 제거율 = 로그 정규 CDF (4.3), 시간 항 없음 | 1초든 20초든 점수 동일 |
| 자세 순서 | 단일 정적 자세 | B1(몸 회전)을 "12방향 평균"으로만 흉내 |

## 2. 결정 변수 (계획 = Plan)

| 묶음 | 변수 | 개수 | 범위 |
|---|---|---|---|
| 자세 순서 | 단계 K개 × 자세 7개 | 14 (K=2) | 시나리오 `pose_bounds` |
| 시간 | 총 시간 T, 단계 분할 비율 | 2 | T 5~20 s, 단계 최소 2 s |
| 세기 | 구역 Z개 세기 s_z | 5 | 0 ~ s_max |
| 합계 | | **21** | |

**구역(몸 기준 5개)**: 가슴 쪽 벽 하단(z 0.72·0.95) / 가슴 쪽 벽 상단(1.18·1.42) / 등 쪽 벽 하단 / 등 쪽 벽 상단 / 천장(4개 바).
- "가슴 쪽 벽"은 몸의 전방 벡터가 향하는 쪽 벽(sign(sin yaw), 0이면 +y). 이렇게 정의하면 기존 좌우 거울·앞뒤 등가 접기(yaw 0~90°)가 그대로 유지된다.
- 단계마다 가슴 쪽 벽이 바뀌면 구역 → 노즐 매핑도 단계별로 다시 계산한다(세기 값 자체는 계획 전체에서 하나).

## 3. 수식

### 4.6 시간 의존 제거 (D 닫힌 식, A 입자 확률)

단일 단계:
```
R_i(t) = R∞_i · (1 − exp(−t / T_r)),   R∞_i = Φ((ln τ_i − ln τ_med)/σ_log)   (4.3)
T_r = adhesion.kinetics.time_constant_s
```

여러 단계 (패치 i, 단계 k의 전단 τ_ik, 시간 t_k): 임계 전단이 τ_c인 입자는 τ_ik > τ_c인 단계에서만 떨어질 수 있다. 단계를 τ_ik 오름차순으로 정렬해 τ_(1) ≤ … ≤ τ_(K), F = 로그 정규 CDF, F(τ_(0)) = 0 이라 하면
```
R_i = Σ_j [F(τ_(j)) − F(τ_(j−1))] · (1 − exp(−(Σ_{k: τ_ik ≥ τ_(j)} t_k) / T_r))
```
K=1이면 단일 단계 식과 같다. 단계 전환 시간 `plan.transition_s` 동안은 제거 0으로 본다(보수적).

- A(입자판): τ > τ_c인 부착 입자가 스텝마다 확률 `1 − exp(−dt/T_r)`로 이탈. 단계가 바뀌면 몸 자세를 바꾸고 부착 입자는 패치를 따라 이동.
- 전제(B 보장): 패치가 자세와 무관한 같은 물질점이어야 한다(휴지 자세에서 샘플링 후 스키닝).

### 4.7 세기, 풍량 한도, 에너지

```
출구 속도  U0_m = s_m · jet.slot.exit_velocity_mps          (기존)
풍량      Q_m  = s_m · fan.rated_flow_m3_min                (9.2 m³/min)
제약      0 ≤ s_m ≤ fan.s_max,   Σ_m s_m ≤ fan.cap_ratio · M
보수      Σ s_m 이 한도를 넘으면 전 구역을 같은 비율로 줄인다 (인코더에서, 평가 전)
에너지    e = (Σ_m s_m^p · T) / (M · T_ref),  p = fan.power_exponent = 3 (팬 상사 법칙)
          현행 운전(전 팬 s=1, T = T_ref = 20 s)이면 e = 1
쾌적 상한  scenario.nozzle_strength_cap (구역 이름 키): 임산부는 chest_low · chest_high ≤ 0.6
```

### 4.4 점수 확장

```
score = Σ_부위 w_부위 · R_부위
        − w_D · Σ_k 불편도_k · t_k / T_ref          (시간 가중 불편도)
        − w_E · e                                   (에너지)
        − w_T · T / T_ref                           (대기 시간, 기본 0)
```

## 5. 인터페이스 변경 (통합 담당)

- `types.py`: `Phase(pose, duration_s)`, `Plan(phases, zone_strengths)` 추가. `NozzleConfig`는 그대로.
- `Evaluator.evaluate_plan(plan, nozzle, body, scenario) -> EvalResult` 추가. `extra`에 `energy`, `duration_s`, 단계별 제거율. 기존 `evaluate(pose, …)`는 변경 없음(시간 항 없는 점근값) → 기존 E2~E4·데이터셋 유효.
- B: `airis.sim.scenario.apply_zone_strengths(nozzle, zone_strengths, torso_yaw, zones=None) -> NozzleConfig`, `nozzles.yaml`에 구역 정의.
- C: `PlanEncoder`(21차원, 한도 보수, 대칭 정규화), 데이터셋 스키마에 계획 열.
- 모델 계약: `predict_plan(body, scenario) -> Plan` (기존 `predict_pose`는 유지).
- E: 단계별 자세 안내, 구역 세기 표시, 장비 제어용 출력(JSON: 구역별 팬 속도, 시간).

## 9. 리스크

- 근거가 약한 상수가 늘어난다(T_r, 에너지 가중). k와 같은 방식으로 민감도에서 결론의 견고함을 확인한다.
- 팬 개별 제어가 장비에서 불가능하면 구역을 "전체 1개"로 줄여 세기·시간만 남긴다. 퓨리움 문의에 추가: 팬별 속도 제어 가능 여부, 정격 이상 운전 가능 여부, 동작 시간 설정 범위.
- 변수가 21개로 늘어 봉우리가 많아질 수 있다. CMA-ES 시작점을 기존 단일 자세 최적(만세·팔 내림)에서 출발시킨다.
